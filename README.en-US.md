### How to Install StarMessage

Double-click the [StarMessageSetup0.1.0.exe](./StarMessageSetup0.1.0.exe) application.

> The application will run by default after installation.

### How to Run StarMessage

> Find StarMessage in the Start menu or on the desktop, then click StarMessage.

***

### How to Run go-ipfs

- ***One-click run go-ipfs***

> First, locate the go-ipfs folder [inside our compressed package].

> Open the go-ipfs folder.

> Click the `ipfs-daemon.cmd` file.

- ***Alternatively, you can run it this way***

> Open cmd/shell.

> Navigate to the disk where the go-ipfs folder is located.

> Enter the following command:

     cd PATH         //PATH is the path where the go-ipfs folder is located
                     //For example: cd D:/software/StarMessage/go-ipfs

> For the first time running go-ipfs, enter the following command:

	ipfs init

> If you have already run go-ipfs before, enter the following command:

	ipfs daemon

> ***Note: Please do not close the cmd window to ensure the daemon remains running.***
